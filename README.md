# gestion-pedidos-uce

Plataforma de gestión de pedidos y entregas: migración de una aplicación monolítica a cinco microservicios con Spring Boot, PostgreSQL, Docker y Docker Compose.

## Microservicios

| Servicio | Responsabilidad |
|---|---|
| customer-service | Gestión de clientes |
| product-service | Gestión de productos |
| order-service | Gestión de pedidos |
| delivery-service | Gestión de entregas |
| notification-service | Gestión de notificaciones |

> Proyecto en construcción.
